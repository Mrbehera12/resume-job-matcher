# Resume-to-Job Matcher & Skill Gap Recommender

An NLP and machine learning project that helps job seekers
discover relevant job opportunities based on their resumes
and identify skills they may need to develop.

## Objectives

- Parse resume information from PDF files.
- Match resumes with relevant job postings.
- Rank jobs using relevance scores.
- Identify missing or underrepresented skills.
- Evaluate matching quality using ranking metrics.
- Build a deployable and monitored application.

## Planned Technology

- Python
- Pandas
- Scikit-learn
- NLP and text similarity
- FastAPI (planned)
- Cloud deployment (planned)

## Project Status

Environment setup and initial scaffolding.

## Privacy

Uploaded resumes should be processed securely.
The application is intended to avoid storing uploaded
resume contents by default.

## Development

Activate the virtual environment:

    source .venv/bin/activate

Install dependencies:

    pip install -r requirements.txt
